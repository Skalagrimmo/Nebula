# 🌌 Nebula 4X

**Nebula 4X** — мобільна космічна 4X-стратегія з RPG-режимом, оптимізована для слабких пристроїв.
A galactic 4X space strategy & RPG game for Android, optimized for low-end devices.

## 🎮 Можливості

- **Два режими гри**: покрокова 4X-стратегія (економіка, дипломатія, війни, технології) та RPG-режим капітана зорельота (торгівля, полювання на піратів, квести)
- 14 зоряних систем, 3 фракції з AI-противниками, тактична зоряна карта з векторним радаром
- Динамічний ринок з коливаннями цін, випадкові галактичні події, система досягнень
- Українська та англійська локалізації
- Повністю офлайн: без зовнішніх сервісів і API-ключів

## 🛠 Збірка

Вимоги: JDK 17+, Android SDK (compileSdk 37).

```bash
# Gradle wrapper не входить до репозиторію — згенеруйте його один раз локально:
gradle wrapper --gradle-version 9.3.1

./gradlew :app:assembleDebug
```

Релізна збірка очікує змінні оточення: `KEYSTORE_PATH`, `STORE_PASSWORD`, `KEY_PASSWORD`.

## 🧪 Тести

```bash
./gradlew :app:testDebugUnitTest
```
